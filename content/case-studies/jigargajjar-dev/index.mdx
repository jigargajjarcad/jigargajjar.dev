## Context and constraints

The specification was written before any application code existed. Four phases of
documentation preceded the first line of TypeScript, and the frozen documents are
treated as the implementation contract rather than as guidance.

## Failures and mistakes

<Callout variant="critical" heading="The budget was unreachable from the start">
  The 90 KB figure was recorded in a table with no derivation. Nothing captured what runtime size it
  assumed, so when React 19 grew the runtime the premise expired silently. It took an empty
  production build to prove it.
</Callout>

## Verification

Every gate runs against the production build and blocks merge. None is advisory.

## Looking back

The phase-one instruction to stand up quality gates against an empty page is the
decision that has paid off most. The budget contradiction surfaced on the first
production build rather than after a feature depended on it.
