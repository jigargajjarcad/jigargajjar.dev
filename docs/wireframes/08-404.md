# Wireframe — `/404`

**Specification source:** [`INTERACTION.md`](../design/INTERACTION.md) §8 · [`ARCHITECTURE.md`](../ARCHITECTURE.md) §4

---

## 1. Purpose

Return a lost reader to `/` or `/work` without friction.

## 2. Audience

Anyone. Most commonly a reader following a stale link — which, on a site where URLs are permanent, most often means a mistyped address or an external link that was wrong when it was written.

## 3. Narrative goal

**Entering:** mild annoyance. They wanted something specific and did not get it.
**Leaving:** back on a useful page, in one action.
**Exit action:** `/` or `/work`.

Density `default`. This is a full page with the site's complete layout, not a bare message.

---

## 4. Mobile — 375 px

```
┌───────────────────────────────────────┐
│ ‹Skip to content›                     │
├───────────────────────────────────────┤
│ Jigar Gajjar            ☰{menu} {theme}│
├───────────────────────────────────────┤
│                          ⟨--space-section-md⟩
│ H1  That page does not exist          │
│                                       │
│ The address may be mistyped, or the   │
│ link that brought you here may have   │
│ been wrong. Nothing here has moved —  │
│ URLs on this site are permanent.      │
│                          ⟨--space-8⟩  │
│                                       │
│ ‹Home {arrow-right}›                  │
│ ‹All four case studies {arrow-right}› │
│                          ⟨--space-section-lg⟩
├───────────────────────────────────────┤
│ FOOTER                                │
└───────────────────────────────────────┘
```

◇ **No humour, no illustration, no "lost in space."** A reader who hit a broken link is mildly annoyed and wants the exit, not a joke. `EXPERIENCE_PRINCIPLES.md` §3 refuses charm as a substitute for usefulness.

◇ **The explanation names the two real causes and rules out a third.** "Nothing here has moved" is worth a sentence, because the most common reader assumption on a 404 is that the content was removed — and on this site, permanent URLs mean it was not.

◇ **Two exits, not four.** `/` for anyone, `/work` for the reader who was probably looking for a case study. Offering `/about`, `/workflow`, `/resume`, and `/connect` as well would be a sitemap, which is what a reader who already knows what they want does not need.

```
│ Jigar Gajjar              Work  Workflow  About  Connect {theme}│
├───────────────────────────────────────────────────────────────┤
│ ⟨--container-prose 68ch, left-aligned within --container-wide⟩ │
│                                                                │
│ H1  That page does not exist                                   │
│                                                                │
│ The address may be mistyped, or the link that brought          │
│ you here may have been wrong. Nothing here has moved —         │
│ URLs on this site are permanent.                               │
│                                                                │
│ ‹Home {arrow-right}›     ‹All four case studies {arrow-right}› │
├───────────────────────────────────────────────────────────────┤
│ FOOTER                                                         │
└───────────────────────────────────────────────────────────────┘
```

◇ **Not centred vertically.** A vertically centred 404 is a device that says "this page is special." It is not special; it is a page with less content, and it should sit where every other page's content sits.

◇ **The layout is identical to every other route.** Header, prose column, footer. A 404 that abandons the site's layout tells the reader they have left the site.

## 7. Component mapping

| Element | Component | Source |
|---|---|---|
| Shell | Header · Footer | `COMPONENT_GUIDELINES.md` §3.1, §3.3 |
| Message | Prose primitive | `ARCHITECTURE.md` §3 |
| Recovery links | Link | §2.1 |

**No new components.** Rendered from `not-found.tsx` (`ARCHITECTURE.md` §3), statically.

## 8. Ledger mapping

Resolves no ledger question. It is a recovery surface, and it is the one route in the system whose job is to be left quickly.

## 9. Design rationale

**A full page, not a bare message.** `ARCHITECTURE.md` §4 requires the 404 to carry the site's complete layout. The header and footer are the recovery paths that work regardless of which two links are offered in the body.

**The copy states a fact the reader would otherwise assume wrongly.** Permanent URLs are a real property of this site (`ARCHITECTURE.md` §4), and saying so converts "they deleted it" into "I mistyped it."

**No search box.** There is no search on this site, and adding one here would be inventing a route's worth of functionality on the page least deserving of it.

## 10. What was deliberately removed

- **Illustration, ASCII art, or a large "404" numeral** — decoration on the page a reader most wants to leave
- **Humour** — a joke costs a reader who is already mildly annoyed
- **A sitemap of every route** — the header already carries navigation
- **Search** — does not exist on this site
- **Automatic redirect after a delay** — takes control of navigation from the reader
- **A reporting or "tell us what went wrong" affordance** — no server, and it asks a reader to do work

## 11. Accessibility

One `<h1>`. Landmarks identical to every other route. The page returns HTTP 404, so assistive technology and crawlers are told what happened rather than only being shown it. Tab order: skip → header → nav → theme → Home → All case studies → footer.
